# Same-session role changes

Record each member's last delivered role identity and display label, independently of the current assignment. At the start of a new turn, compare the current role, pinned revision and room notes with that identity. If it changed, save a notice with the turn's role envelope and advance the delivered identity in the same transaction. Pack changes include the full role; a removed or custom role gets a small envelope with the notice while custom instructions remain in the existing rules. Replaying the same turn returns its original notice, but a later turn does not repeat it. Reopening the database or replacing a session preserves the identity. The notice asks the agent to stop the previous role's duties and hand over open work; it never changes app permissions.

Migration initializes existing members to their current assignments so an upgrade does not falsely report an earlier change. New members start with no role. All role mutation paths snapshot an active turn's old role and instructions before updating; multiple changes preserve the first snapshot. Tests cover pack, custom and removal transitions, repeats, reopen and replacement, and changes while a turn is active.
